# LeadGenius

> LeadGenius provides precision B2B contact and account intelligence for go-to-market teams,
> combining machine learning with a global team of human researchers to build custom datasets.
> The LeadGenius Enrichment API is a RESTful, API-key authenticated service for company enrichment,
> contact enrichment and contact append — offered both as asynchronous Campaigns (batch upload,
> webhook on finalization, retrieve) and as real-time "rapid enrichment" requests.

Note: LeadGenius publishes a file at https://www.leadgenius.com/llms.txt, but its contents are
robots.txt-style crawl directives rather than the llms.txt format. This file was generated by the
API Evangelist enrichment pipeline from apis.yml and the artifacts in this repository.

## APIs

- [LeadGenius Enrichment API](https://docs.leadgenius.com/): Account and contact enrichment, contact append, exclusion lists and real-time rapid enrichment. Base URL https://leadgenius.com, all paths under /api/v1/.

## Specs

- [OpenAPI 3.1 (captured)](openapi/leadgenius-enrichment-api-openapi.yml): 11 operations plus the record-finalized webhook, transcribed from the published reference.
- [Overlay](overlays/leadgenius-enrichment-api-overlay.yaml): API Evangelist enhancements over the captured spec.
- [Webhook catalog](asyncapi/leadgenius-enrichment-webhooks.yml): the record.finalized callback.

## Operations

- createCampaign — POST /api/v1/enrichment/campaigns/
- getUploadRequestSample — GET /api/v1/enrichment/upload/{slug}/
- uploadRecordsToCampaign — POST /api/v1/enrichment/upload/{slug}/
- updateCampaign — PATCH /api/v1/enrichment/update/{slug}/
- retrieveCampaignRecords — GET /api/v1/enrichment/retrieve/{slug}/
- getApiUsageStats — GET /api/v1/enrichment/status/
- uploadExclusionRecords — POST /api/v1/exclusion/upload/
- createRapidEnrichmentRequest — POST /api/v1/enrichment/rapid/
- listEnrichmentRequests — GET /api/v1/enrichment/rapid/
- retrieveEnrichedRecord — GET /api/v1/enrichment/rapid/{id}/
- getEnrichmentStats — GET /api/v1/enrichment/rapid/stats/
